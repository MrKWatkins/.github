# Security

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through the
affected repository's Security tab. Select Advisories, then Report a vulnerability.

Please avoid public issues or pull requests that disclose the vulnerability.

Include the affected version, steps to reproduce the problem, and its likely
impact. A minimal example is helpful.

## Supported versions

Security fixes target the latest release. Older releases are not maintained.

These are personal projects maintained in spare time. There is no guaranteed
response time and no bug bounty.
