# Contributing

These are personal projects developed around my own interests and priorities.

Bug reports and suggestions are welcome. Please check existing issues first
and include enough detail to reproduce any problem.

You're welcome to open a pull request, but review, feedback and merging are
not guaranteed. Please open an issue before starting substantial work to
discuss whether the change fits the project.

Keep changes focused. Include relevant tests and documentation, and follow
the project's existing conventions.

For suspected security vulnerabilities, follow the repository's security
policy rather than opening a public issue.
